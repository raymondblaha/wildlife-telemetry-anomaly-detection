# Research Archive

The original exploratory notebooks and R Markdown files are not copied here by default.

Reasons:

- Many files contain machine-specific paths such as external drive and local desktop references.
- Several notebooks are duplicate or exploratory `copy` variants.
- Some code cells contain exact animal IDs or study-specific labels that should be reviewed before public release.
- Saved notebook outputs may be stale unless rerun from a clean kernel.

Canonical methods should be refactored into `R/`, `src/`, and `scripts/` before publication.
