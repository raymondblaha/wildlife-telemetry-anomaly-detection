# Sensitive Data Policy

This repository is designed to show technical ability without exposing protected research data.

## Do Not Commit

- Raw GPS telemetry.
- Exact coordinates for protected wildlife locations.
- Exact animal IDs from agency or collaborator datasets.
- Unpublished CWD status lists or disease-stage labels.
- Full split manifests containing identifiable animals.
- Local drive paths, collaborator names in paths, or private file structures.
- Saved notebook outputs that have not been reviewed.

## Safe To Commit

- Synthetic sample data.
- Public-safe schemas.
- Reusable preprocessing/model code.
- Configuration templates.
- Method documentation.
- Aggregated metrics after collaborator review.
- Redacted or anonymized examples.

## Portfolio Language

Use language like:

> This public repository demonstrates the reproducible pipeline design. Raw telemetry and unpublished collaborator data are excluded for privacy and research-governance reasons.
